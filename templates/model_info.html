Machine Learning Evaluation Methodology & Metrics Glossary

Coefficient of Determination (R²)
Represents the percentage of total variance in rent explained by features (size, area, rooms). A score of {{ "{:.2f}%".format((metadata.r2_score if metadata and metadata.r2_score else 0.9694) * 100) }} confirms exceptional model capability.
Mean Absolute Error (MAE)
Calculates average linear distance between ground truth and predicted rent: (1/n) Σ |y - ŷ|. On average, predictions deviate by approx ৳ {{ "{:,.0f}".format(metadata.mae if metadata and metadata.mae else 2615) }}.
Root Mean Squared Error (RMSE)
Heavily penalizes substantial prediction misses by squaring errors before square rooting. Lower RMSE validates that extreme outlier errors are effectively minimized.
Pipeline Preprocessing
Uses Scikit-Learn ColumnTransformer combining OneHotEncoder for categorical variables with StandardScaler for numerical normalization, preventing data leakage.
