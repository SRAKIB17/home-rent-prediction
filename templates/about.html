About the Project

An academic machine learning system designed to automate and standardize residential rent estimation in urban Bangladesh.

🎯 Project Objective & Problem Statement

In rapidly expanding urban metropolises like Dhaka, determining a fair monthly home rental price is challenging due to volatile pricing, subjective landlord estimates, and fluctuating amenity valuations across different neighborhoods (e.g., Gulshan vs. Mirpur vs. Uttara).

This Home Rent Prediction System implements a data-driven Machine Learning approach. By training multiple supervised regression models on historical housing data with features such as sqft area, location, bedroom count, bathrooms, floor levels, furnishing, and parking, the system predicts accurate, objective monthly rental estimates in BDT (৳).

⚙️ Machine Learning Pipeline Architecture

1. Data Preprocessing

  • Handling Missing Values & Duplicates
  • Elimination of Impossible Outliers
  • OneHotEncoding for Categorical Features
  • StandardScaler for Continuous Values

2. Model Exploration

  • Linear Regression (Baseline)
  • Decision Tree Regressor
  • Random Forest Regressor (Ensemble)
  • Gradient Boosting Regressor

3. Deployment & Web App

  • Full Scikit-Learn Pipeline Serialization via Joblib
  • Flask Microframework for Web UI & JSON API
  • Real-time Validation & BDT Formatting
